Add a weekly calendar below the term radio buttons that shows the courses a user has selected. The calendar should only show Monday through Friday from 9am to 9pm, and it should only show classes from the currently selected term, so Fall, Winter, and Spring each remembering their own selections. If no courses are selected, the calendar should tell the user to select a course. Selected courses should show on the correct days and time. On a computer screen, show two columns of course cards next to the calendar, and on mobile show the calendar above the cards. Use the DayPilot weekly calendar tutorial: https://code.daypilot.org/42221/react-weekly-calendar-tutorial
